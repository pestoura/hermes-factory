# Hermes Software Factory — Operating Model v1

**Status:** HISTORICAL / SUPERSEDED BY v1.2  
**Implementation authority:** NOT GRANTED

This file is retained as a provenance marker for the original v1 operating model. The complete historical content remains available in Git history.

Current operating model is defined by the Architecture v1.2 review/specification and ADR-0016 through ADR-0020, including:

- autonomous atomic stage handoff;
- first-class UAT/Finding/bounded Rework;
- asynchronous revision-bound HITL;
- Hermes Kanban/Dispatcher for event-driven work;
- native Hermes Profile/Agent cron for internal time-driven work;
- Jarvas CLI as first greenfield Factory product.
